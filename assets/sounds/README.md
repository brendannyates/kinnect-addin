# Notification sounds

Put the four kin-nect sounds here, named `bing`, `boom`, `bop` and `bow`, each as `.mp3`, `.wav`, `.ogg` or `.m4a` (e.g. `bing.mp3`). Each computer picks one in Kinnect > Settings. A missing file falls back to the built-in chime.

This repo is public: only add sounds you have the right to publish.
